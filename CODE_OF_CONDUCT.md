# Code of conduct

QEnvS adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every project space: issues, pull requests, discussions and
any other channel tied to the project.

In short: be respectful, assume good faith, give and accept constructive technical
criticism, and keep discussions about the physics and the code, not about people.

## Reporting

Report unacceptable behaviour privately to the maintainer, Beomdo Park
([@beomdo-park](https://github.com/beomdo-park)), by email to the author address listed in
`pyproject.toml`. Reports are handled confidentially. The enforcement guidelines of the
Contributor Covenant 2.1 apply.
